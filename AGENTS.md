# Политика RIZORIX

- Тексты и документация — на русском. Сайт публикуется из `main` через GitHub Pages.
- Сохранять адрес https://matthew-mbn.github.io/neon-climb-privacy/ для совместимости с установленными APK.
- Оформление соответствует `rizorix-changelog`: тёмный фон, бирюзовый/розовый неон, Tiny5 Duo в заголовках, читаемый основной текст и мобильная вёрстка.
- При визуальных правках сохранять содержание политики, контакты, ссылки и дату её редакции. Содержательные изменения обосновывать реальным поведением игры.
- По постоянному указанию пользователя от 2026-11-15 проверять и актуализировать политику после каждого обновления RIZORIX. Сверять реальные сохранения, SDK, рекламу, разрешения, сеть, покупки, обращения и удаление данных. Если обработка данных не менялась, обновлять отметку проверки версии, сохраняя дату содержательной редакции. После содержательных правок обновлять дату редакции и публиковать сайт; отдельное разрешение не требуется.
- Не подключать аналитику, сторонние шрифтовые сервисы и тяжёлые зависимости без необходимости. Не публиковать приватные исходники игры и данные игроков.
- Перед публикацией проверять текст и вёрстку; после отправки — сборку Pages и доступную страницу.
