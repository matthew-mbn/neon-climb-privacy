# RIZORIX — политика конфиденциальности

Страница игры RIZORIX от EASE STD. Адрес публикации сохранён для совместимости с установленными версиями игры.

Сайт: https://matthew-mbn.github.io/neon-climb-privacy/.

Оформление согласовано с [историей обновлений](https://matthew-mbn.github.io/rizorix-changelog/): тёмная палитра, бирюзовые и розовые акценты, локальный Tiny5 Duo, адаптивная навигация по разделам. Шрифт распространяется по OFL; лицензия находится в `assets/Tiny5Duo-OFL.txt`.

Изменение дизайна от 15 ноября 2026 не меняет текст политики и дату её редакции — 14 ноября 2026. Сайт статический, без JavaScript и аналитики. Публикация: ветка `main`, корень репозитория, GitHub Pages.
